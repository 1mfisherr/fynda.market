## Where they agree

- **No login.** Eight German portals have organiser logins and stale data. No segment wants one more account on a directory. flohmarktkalender.ch offers plain e-mail precisely for older organisers.
- **Nobody shows "confirmed by the organiser on <date>"**, and nobody gets a cancellation to visitors — every competitor's FAQ admits organisers forget to tell them. The Swiss 1600 "does it take place?" phone line died in 2022 and nothing replaced it.
- **The cheapest thing organisers would actually use:** a signed link in an e-mail before each date — *it's on / cancelled / something changed* — that updates the page, the stamp, the digest and the ICS within the hour. Return frequency equals event frequency; do not design for weekly use.
- **Organisers' real daily pain is vendors, not visitors** (stall filling, allocation, fees). The tools that grew in this niche (flohmap.de, OrgaBroc) are stall tools with a directory as by-product. Out of scope for Fynda, but a vendor waiting-list address on a market page is the one thing a directory can offer that a booking tool cannot.
- **Do not build before Germany:** an owner dashboard (Flohmap.de gives German organisers one for free and data is no fresher), broadcast to Google/Facebook (platform reviews, stored tokens, used 0–3× a year), stall booking.
